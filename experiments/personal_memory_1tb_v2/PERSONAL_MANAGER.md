# Единый помощник GLYPH

Один вход для существующей личной памяти в Ubuntu/WSL:

```bash
bash experiments/personal_memory_1tb_v2/start_personal_manager.sh
```

Меню показывает текущую рабочую папку и четыре действия:

1. **Открыть память** — запускает существующее веб-приложение. Оно выводит локальную ссылку. Ctrl+C в терминале приложения возвращает меню после завершения сервера.
2. **Создать резервную копию** — в новую папку; приложение должно быть закрыто. Блокировки проверяются, файлы перечитываются, версии восстанавливаются для проверки. Помощник сохраняет контрольную сумму отдельно от копии и выводит её для независимого хранения.
3. **Восстановить копию** — выбрать ранее записанную копию или указать её путь и ранее сохранённую контрольную сумму. Восстановление только в новую папку. После успешной проверки появляется новая настройка, рабочая память не переключается.
4. **Выбрать рабочую память** — выбрать папку и подтвердить словом `ДА`. Переключается настройка запуска, данные не перемещаются и не удаляются.

Программа не удаляет файлы в этих четырёх действиях. Удаление документов остаётся отдельным подтверждаемым действием в веб-приложении.

## Настройки

По умолчанию `$GLYPH_PILOT_HOME` или `$HOME/GlyphPilot`. Помощник хранит частные локальные настройки в `personal-manager`: неизменяемые профили, атомарный указатель `ACTIVE` и отдельный каталог контрольных сумм копий. Эти файлы не публикуются в Git. Два экземпляра помощника одновременно не допускаются.

При первом запуске ищется только ранее известная квитанция архива в `GLYPH-V2-runs`, с прежним закреплённым SHA-256 и доверенным Precomp. Личные исходные папки не сканируются. Новые хеши автоматически не принимаются. Если исходный архив недоступен, меню позволяет восстановить копию по независимо сохранённой сумме и указать доверенный декодер.

Параметры: `--home`, `--state`, `--max-bytes`. По умолчанию предел копирования и суммарной проверки уникальных версий — 1 ГиБ, допустимо до 64 ГиБ. Это ограничение текущего помощника, **не подтверждение готовности резервировать 1 ТБ**. Для большей памяти он остановится, а не выдаст неполную копию за готовую.

## Границы

Это терминальное меню, запускающее существующий интерфейс в браузере; не графический установщик. Копия данных не включает приложение и Precomp и не зашифрована. Сохраните код нужной версии, доверенный декодер и контрольную сумму отдельно. Копия на том же диске не защищает от потери диска.

Частично созданные папки после ошибки не активируются и не удаляются автоматически. Исходная рабочая память остаётся на месте. Используйте новую папку для повторения операции. История может содержать старые данные; ограничения удаления и доверенной локальной файловой системы описаны в `PERSONAL_BACKUP.md`.

## Проверка

`tests/test_personal_manager.py` проверяет меню копирования, восстановление двух версий, переключение при недоступных исходных каталогах, сохранение прежнего выбора при повреждении копии, блокировки, неверную конфигурацию и раздельность папок. Запуск приложения в этом тесте проверяется по аргументам вызова, без подмены этого результата полноценным пользовательским испытанием браузера.

Результат разработки: общий набор 184 теста — 178 прошли, 6 пропущены, ошибок нет (52,762 с). После добавления отдельного сценария восстановления через меню без исходных папок и настроек: все 6 тестов помощника прошли (0,281 с). Синтетические данные, Linux-среда разработки; это не измерение ноутбука и не испытание физического отказа диска.
