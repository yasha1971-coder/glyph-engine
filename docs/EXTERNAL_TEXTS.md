# Внешние тексты GLYPH

Правило Якова от 25.11.2026.

1. Любой внешний текст, который написал ChatGPT (Codex), включая issue, описание PR, комментарий, письмо и черновик для Якова, начинается со следующей строки. Копировать её целиком, без кавычек и без текста перед ней.

   ```text
   [written by ChatGPT (AI) at the author's request; checked by the author]
   ```

2. Если текст написал Claude, первая строка выглядит так:

   ```text
   [written by Claude (AI) at the author's request; checked by the author]
   ```

   Подпись указывает фактического ИИ-автора.
3. Простое «спасибо» без другого содержания можно отправить без подписи.
4. Для Hacker News Яков пишет текст сам. ИИ может подготовить только опорные пункты на русском. Это распространяется и на черновики постов и комментариев.
5. ИИ готовит черновик. Перед отправкой Яков проверяет текст, а численные утверждения сверяются с исходными логами. Отправляет Яков или контролёр по его прямому слову. Строка подписи в черновике сама по себе не подтверждает прохождение проверки.
